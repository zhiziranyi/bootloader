1. 设备串口与 Bootloader CLI

上位机独占串口。先关闭友善串口助手等其他串口程序，再选择 COM3 并连接。若设备当前在 APP，手动按复位键后，在 Bootloader 的 3 秒窗口点击“发送任意字符进入 CLI”。

2. OTA 升级

先启动下方的固件服务器；目标槽必须与当前运行槽相反。固件已经由发布工具打包并用设备内置公钥验签。

3. 发布签名固件

构建 APP-A / APP-B，生成 .pkg、发布清单，并在电脑端复核签名。

4. OTA 固件服务器

服务 firmware\ 目录。电脑网卡共享时，设备通常访问 192.168.137.1。

5. 串口烧录

此操作进入 STM32 ROM 串口下载模式。烧录 Bootloader 前：BOOT0 接 3.3V，按复位；完成后把 BOOT0 接回 GND 再复位。不会烧除 APP-A/B 以外的分区，具体取决于所选目标。

6. 密钥轮换

量产前使用。会生成全新签名密钥、备份旧公钥、重新构建和打包。
